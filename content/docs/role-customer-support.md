Customer Support sets up every new client, follows a fixed call schedule and answers every client question, so that clients keep using iSuite AI and **70% of them stay**.

| Item | Detail |
| --- | --- |
| Reports to | General Manager |
| Clients | Every client: direct (Meta ads) and those brought by Solution Partners |
| Trained by | Training Head |

## Responsibilities

### Setup

- Set up every new client: account, WhatsApp number, Meta approval and AI rules.
- Use Marketing's how-to guides for each product.

### Call schedule

Calls follow this schedule, not a call every day. The free trial is 14 days.

| When | Call | Goal |
| --- | --- | --- |
| Trial day 0 | Welcome + setup | Account, WhatsApp and AI working the same day |
| Trial day 3 | Check-in | Are they using it? Fix any problem |
| Trial day 7 | Value call | Show the feature that helps their business most |
| Trial day 12 | Before the trial ends | Answer doubts, help them make the first payment |
| Paid, month 1 | Every week | Make sure they use it every week |
| Paid, after month 1 | Every month | Health check |
| 60 days before renewal | Renewal call | Make sure they renew |

### Support

- Answer every client question the same working day.
- Send product problems and feature requests to the GM.

### Retention

- Every month, check which clients are active: using the app and the WhatsApp AI.
- Call any client who has stopped using it.

## Daily, weekly, monthly

| When | What |
| --- | --- |
| Every working day | Setups and scheduled calls, client questions |
| Every working day, 6:00 PM | Send numbers for the KPI board |
| Weekly | Calls to clients in their first paid month |
| Monthly | Active-client check and health-check calls |

## KPIs

| KPI | Target |
| --- | --- |
| Setup | Done on trial day 0 |
| Call schedule | 100% of calls made on the planned day |
| Trial → paid | About 13% on average, to reach 25 direct paying customers |
| Clients retained | 70% |
| Client questions | Answered the same working day |

## December

- Learn every product and practise setups on demo accounts.
- Prepare a short script for each call in the schedule.
- Pass the product test (80% or more) and 3 mock setups.
